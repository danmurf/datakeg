<objective>
Create a standalone `merge` subcommand that combines per-document JSONL files into master train/valid/test files.

**Purpose:** Users can run the generate pipeline with `--skip-merge`, inspect per-document outputs, and later merge them when ready. This enables iterative workflows and debugging.

**Output:** New `merge` subcommand accessible via `datakeg merge <output>`
</objective>

Create a new file `cmd/datakeg/commands/merge.go` with the merge command implementation:

**Structure:**

1. Import necessary packages:
   - `fmt`, `os`, `path/filepath`, `strings`
   - `github.com/danmurf/datakeg/internal/writer`

2. Define `ExecuteMergePipeline` function that:
   - Takes `outputDir string` as parameter
   - Scans outputDir for `{name}_train.jsonl`, `{name}_valid.jsonl`, `{name}_test.jsonl` files
   - Collects all pairs from matching files
   - Writes consolidated master files: `train.jsonl`, `valid.jsonl`, `test.jsonl`

3. Implement file discovery logic:
   ```go
   // Pattern: *_{split}.jsonl where split is train, valid, or test
   // For each split type, collect all matching files and concatenate their contents
   ```

4. Implement merging logic:
   - Read all per-document files for each split type
   - Collect all TrainingPair objects
   - Write to master file using existing `writer.WriteJSONL`
   - Skip splits with no pairs (don't create empty files)

5. Progress output:
   - Show count of files processed per split
   - Show total pairs written to master files
   - Display: "Merged N files into train.jsonl (M total pairs)"

**Error handling:**
- Return error if outputDir doesn't exist
- Return error if no per-document files found (helpful message)
- Return descriptive errors on file read/write failures

Add the merge subcommand to the CLI in `cmd/datakeg/main.go`:

1. Add `mergeCmd` variable definition:
   ```go
   var mergeCmd = &cobra.Command{
       Use:   "merge <output>",
       Short: "Merge per-document JSONL files into master train/valid/test files",
       Long:  `Merge per-document files (generated with --skip-merge) into master train.jsonl, valid.jsonl, and test.jsonl files.`,
       Args:  cobra.ExactArgs(1),
       RunE:  runMerge,
   }
   ```

2. Add `runMerge` function:
   ```go
   func runMerge(cmd *cobra.Command, args []string) error {
       outputPath := args[0]
       return commands.ExecuteMergePipeline(outputPath)
   }
   ```

3. Register command in `init()`:
   ```go
   RootCmd.AddCommand(mergeCmd)
   ```

4. Add command documentation in the root command's Long description (optional, for better `datakeg --help` output)
