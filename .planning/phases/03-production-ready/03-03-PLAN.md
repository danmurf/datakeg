<task type="auto">
  <name>Audit and improve generate command errors</name>
  <files>cmd/datakeg/commands/generate.go</files>
  <action>
Review and improve all error messages in `ExecuteGeneratePipeline` to include actionable guidance:

**Error cases to improve:**

1. **Source directory errors:**
   - `load documents: %w` → "Could not read source directory. Check that the path exists and you have read permissions."

2. **No documents found:**
   - Current: `no .md or .txt files found in %s`
   - Improve: "No markdown (.md) or text (.txt) files found in [path]. Add some documentation files to the source directory and try again."

3. **Ollama connection errors:**
   - Current: `create ollama client: %w`
   - Improve: "Could not connect to Ollama. Make sure Ollama is running (ollama serve) and the model is available (ollama pull [model-name])."

4. **Generation errors:**
   - `generate train pairs for %s: %w` → "Failed to generate training pairs for [filename]. This may be a temporary Ollama issue. Try again, or try a different model."
   - Similar pattern for valid/test generation errors

5. **Output directory errors:**
   - `create output directory: %w` → "Could not create output directory [path]. Check that you have write permissions and the path is valid."

6. **File write errors:**
   - `write train.jsonl: %w` → "Failed to write [filename]. Check disk space and write permissions."

**Pattern for all errors:**
```
[Short summary of what failed]
[Actionable guidance on how to fix it]
[Optional: technical details for debugging]
```

Wrap errors with `fmt.Errorf` using this pattern consistently.
</action>
  <verify>grep -n "Could not\|Check that\|Make sure\|Add some\|Try" cmd/datakeg/commands/generate.go | wc -l</verify>
  <done>All error messages in generate command include actionable guidance</done>
</task>
