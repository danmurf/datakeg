<task type="auto">
  <name>Task 2: Create embedded prompt templates</name>
  <files>templates/train.tmpl, templates/valid.tmpl, templates/test.tmpl, internal/templates/templates.go</files>
  <action>
1. Create templates/ directory at project root

2. Create templates/train.tmpl:
```
You are generating training data for an LLM. Given the following documentation, generate exactly {{.PairCount}} question-answer pairs.

Document:
{{.DocumentContent}}

Generate {{.PairCount}} diverse question-answer pairs about this content. Output as JSON array:
[{"prompt": "question here", "completion": "answer here"}, ...]

Return ONLY the JSON array, no other text.
```

3. Create templates/valid.tmpl (similar but emphasize validation):
```
You are generating validation data for an LLM. Given the following documentation, generate exactly {{.PairCount}} question-answer pairs that test understanding.

Document:
{{.DocumentContent}}

Generate {{.PairCount}} question-answer pairs that validate comprehension of this content. Output as JSON array:
[{"prompt": "question here", "completion": "answer here"}, ...]

Return ONLY the JSON array, no other text.
```

4. Create templates/test.tmpl (similar but emphasize evaluation):
```
You are generating test data for an LLM. Given the following documentation, generate exactly {{.PairCount}} challenging question-answer pairs for evaluation.

Document:
{{.DocumentContent}}

Generate {{.PairCount}} challenging question-answer pairs to evaluate understanding. Output as JSON array:
[{"prompt": "question here", "completion": "answer here"}, ...]

Return ONLY the JSON array, no other text.
```

5. Create internal/templates/templates.go:

PromptData struct:
- DocumentContent string
- PairCount int
- DocumentName string (for future use)

Embed directive at package level:
//go:embed templates/*.tmpl
var templateFS embed.FS

NOTE: The embed directive path is relative to the file containing it.
Since templates.go is in internal/templates/, and template files are in templates/ at project root,
the embed path needs to reference ../../templates/*.tmpl OR move the embed to a file at project root.

SOLUTION: Create the embed at project root level. Add embed.go in project root:
```go
package datakeg

import "embed"

//go:embed templates/*.tmpl
var TemplateFS embed.FS
```

Then in internal/templates/templates.go, accept the FS as parameter or use a package-level variable set during init.

SIMPLER SOLUTION: Put templates directory inside internal/templates/ so the embed works naturally:
- internal/templates/templates/train.tmpl (etc)
- Embed path: templates/*.tmpl

Actually, the cleanest approach per Go conventions:
- Keep templates/ at project root
- Create internal/templates/templates.go that receives the embedded FS from cmd/datakeg/main.go

For simplicity in this phase, put template files in internal/templates/prompts/:
- internal/templates/prompts/train.tmpl
- internal/templates/prompts/valid.tmpl
- internal/templates/prompts/test.tmpl

Then embed directive in internal/templates/templates.go:
//go:embed prompts/*.tmpl
var promptFS embed.FS

ExecuteTemplate function:
- Signature: func ExecuteTemplate(name string, data PromptData) (string, error)
- Use template.ParseFS(promptFS, "prompts/"+name)
- Execute with data into strings.Builder
- Return builder.String()

Follow patterns from RESEARCH.md Pattern 5 (Embedded Templates).
