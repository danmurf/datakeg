  <action>
**cmd/datakeg/commands/list_providers.go** - New file:

Create `ExecuteListProviders() error` function:

1. Print "Available providers:\n"

2. Check Ollama status:
   - Try creating an Ollama provider (or just check if ollama.NewClient() succeeds)
   - If configured: print "  ollama: Configured"
   - If configured, query for local models by calling the Ollama API's list endpoint. Use the existing ollama package's client to call the tag list API. If the Ollama client supports listing models (check `api.Client` methods), use it. Otherwise, make a simple GET to `OLLAMA_HOST/api/tags`.
   - Print models as indented list: "    Models: model1, model2, model3"
   - If not configured: print "  ollama: Not configured (OLLAMA_HOST not set or Ollama not running)"

3. Check OpenRouter status:
   - Check if `OPENROUTER_API_KEY` env var is set (non-empty). Do NOT reveal the key value.
   - If set: print "  openrouter: Configured"
   - If set, query OpenRouter models API: GET `https://openrouter.ai/api/v1/models` with auth header. Parse response, show top 10 model IDs as a sample (the full list is 500+).
   - Print: "    Models (sample): meta-llama/llama-3-70b, google/gemma-2-27b, ..." and "    See https://openrouter.ai/models for full list"
   - If not set: print "  openrouter: Not configured (OPENROUTER_API_KEY not set)"
   - If API call fails (network error, auth error): print "  openrouter: Configured (could not fetch models: <error>)"

4. Model querying should have a short timeout (10 seconds) and should not block the command if providers are slow.

**main.go changes:**
- Add `listProvidersCmd` cobra.Command variable:
  ```
  Use: "list-providers"
  Short: "List available LLM providers and their configuration status"
  ```
- RunE calls `commands.ExecuteListProviders()`
- In `init()`, add: `RootCmd.AddCommand(listProvidersCmd)`

Use `context.WithTimeout(context.Background(), 10*time.Second)` for model listing API calls. If timeout hits, show "could not fetch models (timed out)" instead of hanging.

**internal/provider/provider_test.go** - Factory and type tests:
- `TestNewProvider_Ollama`: Call `NewProvider(ProviderOllama)` - succeeds if Ollama available, returns error if not. Skip with `t.Skip` if OLLAMA_HOST not set.
- `TestNewProvider_OpenRouter`: Set OPENROUTER_API_KEY via t.Setenv, call `NewProvider(ProviderOpenRouter)` - should succeed (returns provider, not nil). Unset key - should return error with "OPENROUTER_API_KEY not set" message.
- `TestNewProvider_Unknown`: Call `NewProvider("invalid")` - should return error containing "unknown provider".
- `TestProviderType_Constants`: Verify ProviderOllama == "ollama" and ProviderOpenRouter == "openrouter".

**internal/provider/openrouter_test.go** - OpenRouter unit tests with httptest:
- Use `net/http/httptest` to create a mock OpenRouter server. This avoids real API calls.
- `TestOpenRouterProvider_Generate_Success`: Mock server returns valid chat completion response with usage data. Verify response text, usage metadata (prompt tokens, completion tokens, cost).
- `TestOpenRouterProvider_Generate_AuthError`: Mock returns 401. Verify error message contains "authentication" and actionable guidance.
- `TestOpenRouterProvider_Generate_RateLimit`: Mock returns 429 first, then 200. Verify retry succeeds.
- `TestOpenRouterProvider_Generate_ServerError`: Mock returns 500 first, then 200. Verify retry succeeds.
- `TestOpenRouterProvider_Generate_BadRequest`: Mock returns 400. Verify fails immediately (no retry).
- `TestOpenRouterProvider_Generate_EmptyChoices`: Mock returns 200 with empty choices array. Verify error about no response.
- `TestOpenRouterProvider_Generate_ContextCancelled`: Pass cancelled context. Verify returns quickly with context error.
- To test with mock server, the OpenRouterProvider needs its `baseURL` to be configurable. If NewOpenRouterProvider hardcodes the URL, add an unexported helper: `newOpenRouterProviderWithURL(apiKey, baseURL string) *OpenRouterProvider` for testing. Or make baseURL a field set in the constructor that defaults to the real URL but can be overridden in tests.

**internal/cost/estimator_test.go** - Cost calculation tests:
- `TestEstimateTokens`: Table-driven tests:
  - Empty string -> 0
  - "hello" (5 chars) -> 2 (ceil(5/4))
  - 1000 chars -> 250
  - 4 chars -> 1
  - 1 char -> 1
- `TestEstimateCost` or `TestEstimateRunCost`: Verify cost calculation with known inputs. E.g., 1M prompt tokens at $1/M = $1.00.
- `TestTracker_Add`: Add multiple UsageMetadata, verify totals. Add nil - verify no panic.
- `TestTracker_Summary`: Verify formatted output string contains token counts and cost.

All tests should use `t.Parallel()` where safe (no shared mutable state).
Run `make lint && make test` after writing all tests.
