  <action>
  **Create directory and four conversion template files:**

  Create `internal/templates/conversions/` directory.

  **mistral-instruct.tmpl** (for completion format input):
  This template converts TrainingPair (prompt/completion) to Mistral Instruct format.
  Template content (raw text, NOT Go code -- this is the template file itself):
  ```
  {"text": "<s>[INST] {{.Prompt}} [/INST]{{.Completion}}</s>"}
  ```
  Note: The template output must be valid JSON. The `.Prompt` and `.Completion` fields come from writer.TrainingPair. Use `text/template` syntax (NOT html/template -- no HTML escaping). The special tokens `[INST]`, `[/INST]`, `<s>`, `</s>` must appear literally.

  **llama3-instruct.tmpl** (for chat format input):
  Converts ChatMessage (messages array) to Llama 3 format.
  Template content:
  ```
  {"text": "<|begin_of_text|>{{range .Messages}}<|start_header_id|>{{.Role}}<|end_header_id|>\n\n{{.Content}}<|eot_id|>{{end}}"}
  ```

  **chatml.tmpl** (for chat format input):
  Converts ChatMessage to ChatML format.
  Template content:
  ```
  {"text": "{{range .Messages}}<|im_start|>{{.Role}}\n{{.Content}}<|im_end|>\n{{end}}"}
  ```

  **deepseek-r1.tmpl** (for reasoning format input):
  Converts ReasoningPair (question/reasoning/answer) to DeepSeek-R1 integrated format.
  Template content:
  ```
  {"prompt": "{{.Question}}", "completion": "{{.Reasoning}}\n\n{{.Answer}}"}
  ```

  IMPORTANT: These templates will have a problem with JSON special characters in field values (quotes, newlines, backslashes in .Prompt, .Completion, etc.). To handle this properly, add a custom template function `jsonEscape` that JSON-encodes a string and strips the surrounding quotes. Register this function when parsing templates. Then use it in templates like `{{.Prompt | jsonEscape}}` instead of `{{.Prompt}}`. ALL field references in ALL four templates must use `| jsonEscape`.

  Updated template examples with escaping:
  - mistral-instruct.tmpl: `{"text": "<s>[INST] {{.Prompt | jsonEscape}} [/INST]{{.Completion | jsonEscape}}</s>"}`
  - llama3-instruct.tmpl: `{"text": "<|begin_of_text|>{{range .Messages}}<|start_header_id|>{{.Role | jsonEscape}}<|end_header_id|>\n\n{{.Content | jsonEscape}}<|eot_id|>{{end}}"}`
  - chatml.tmpl: `{"text": "{{range .Messages}}<|im_start|>{{.Role | jsonEscape}}\n{{.Content | jsonEscape}}<|im_end|>\n{{end}}"}`
  - deepseek-r1.tmpl: `{"prompt": "{{.Question | jsonEscape}}", "completion": "{{.Reasoning | jsonEscape}}\n\n{{.Answer | jsonEscape}}"}`

  **Extend internal/templates/templates.go:**

  1. Add a second embed directive for conversion templates:
     ```go
     //go:embed conversions/*.tmpl
     var conversionFS embed.FS
     ```

  2. Add a `jsonEscape` template function:
     ```go
     func jsonEscape(s string) string {
         b, err := json.Marshal(s)
         if err != nil {
             return s
         }
         // Strip surrounding quotes from JSON string
         return string(b[1 : len(b)-1])
     }
     ```
     Add `"encoding/json"` to imports.

  3. Add `LoadConversionTemplate(name string) (*template.Template, error)`:
     - Create template with `template.New(name).Funcs(template.FuncMap{"jsonEscape": jsonEscape})`
     - Read template content from conversionFS: `content, err := fs.ReadFile(conversionFS, "conversions/"+name+".tmpl")`
     - Parse with `tmpl.Parse(string(content))`
     - Return parsed template or wrapped error
     - Add `"io/fs"` to imports.

  4. Add `LoadCustomConversionTemplate(filePath string) (*template.Template, error)`:
     - Read file content with `os.ReadFile(filePath)`
     - Create template with `template.New(filepath.Base(filePath)).Funcs(template.FuncMap{"jsonEscape": jsonEscape})`
     - Parse with `tmpl.Parse(string(content))`
     - Return parsed template or wrapped error
     - Add `"os"` and `"path/filepath"` to imports.

  5. Add `ListConversionTemplates() ([]string, error)`:
     - Read directory entries from conversionFS: `entries, err := fs.ReadDir(conversionFS, "conversions")`
     - Collect names (strip `.tmpl` extension) into a sorted slice
     - Return the slice

  4. `TestListConversionTemplates`: Call ListConversionTemplates(), verify it returns 4 entries: "chatml", "deepseek-r1", "llama3-instruct", "mistral-instruct" (alphabetical).

  5. `TestJsonEscape`: Test the jsonEscape function with strings containing quotes, newlines, backslashes, and Unicode. Verify proper escaping.

  <name>Task 2: Create converter package with ConvertJSONL, DetectFormat, and ValidateTemplate</name>
  <files>internal/converter/converter.go, internal/converter/converter_test.go</files>

  **Create internal/converter/converter.go:**

  Package `converter` with these imports: `encoding/json`, `fmt`, `io`, `os`, `strings`, `text/template`, and the project packages `github.com/danmurf/datakeg/internal/generator` and `github.com/danmurf/datakeg/internal/writer`.

  1. **DetectFormat(jsonLine []byte) (generator.FormatType, error):**
     - Unmarshal jsonLine into `map[string]interface{}`
     - Check for chat format: if "messages" key exists and is a non-empty array, return `generator.FormatChat`
     - Check for reasoning format: if "question", "reasoning", and "answer" keys all exist, return `generator.FormatReasoning`
     - Check for completion format: if "prompt" and "completion" keys exist, return `generator.FormatCompletion`
     - Otherwise return error: `fmt.Errorf("unknown JSONL format: could not detect format from fields. Expected completion (prompt/completion), chat (messages), or reasoning (question/reasoning/answer)")`

  2. **DetectFormatFromFile(filePath string) (generator.FormatType, error):**
     - Open file, read first line using `bufio.Scanner`
     - If file is empty or no lines, return error
     - Call DetectFormat with the first line bytes
     - Close file, return result
     - Add `"bufio"` to imports.

  3. **ValidateTemplate(tmpl *template.Template, format generator.FormatType) error:**
     - Create sample data based on format:
       - FormatCompletion: `writer.TrainingPair{Prompt: "test prompt", Completion: "test completion"}`
       - FormatChat: `writer.ChatMessage{Messages: []writer.Message{{Role: "user", Content: "test"}, {Role: "assistant", Content: "test"}}}`
       - FormatReasoning: `writer.ReasoningPair{Question: "test question", Reasoning: "<think>test reasoning</think>", Answer: "test answer"}`
     - Execute template with sample data into a `strings.Builder`
     - If template execution fails, return error: `fmt.Errorf("template execution failed with %s format: %w", format, err)`
     - Verify output is valid JSON by attempting `json.Unmarshal` into `interface{}`
     - If not valid JSON, return error: `fmt.Errorf("template output is not valid JSON for %s format: %w\nOutput: %s", format, err, buf.String())`
     - Return nil on success

  4. **ConvertJSONL(inputPath, outputPath string, tmpl *template.Template, sourceFormat generator.FormatType) (int, error):**
     Returns (linesConverted, error).
     - Open input file for reading
     - Create output file for writing
     - Use `bufio.Scanner` to read line-by-line (NOT json.Decoder -- JSONL is one JSON object per line, and Scanner handles this cleanly without issues with trailing newlines)
     - Set scanner buffer size to 1MB to handle long lines: `scanner.Buffer(make([]byte, 0, 1024*1024), 1024*1024)`
     - For each non-empty line:
       - Track line number for error messages
       - Unmarshal into the appropriate struct based on sourceFormat:
         - FormatCompletion -> `writer.TrainingPair`
         - FormatChat -> `writer.ChatMessage`
         - FormatReasoning -> `writer.ReasoningPair`
       - If unmarshal fails, return error with line number: `fmt.Errorf("line %d: failed to parse %s format: %w", lineNum, sourceFormat, err)`
       - Execute template with the unmarshalled data into a `strings.Builder`
       - If template execution fails, return error with line number
       - Write template output + "\n" to output file
       - Increment linesConverted counter
     - Check scanner.Err() after loop
     - Sync and close output file
     - Return (linesConverted, nil)
